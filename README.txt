PROLOG PRACTICALS - QUESTIONS 26 TO 40
======================================

Files q26.pl through q39.pl contain SWI-Prolog programs.
File q40.html contains the HTML example for the WordPress practical.

HOW TO RUN A PROLOG FILE (Ubuntu / VS Code)
1. Open a terminal in this folder.
2. Start SWI-Prolog:
       swipl
3. Load a file, for example:
       [q26].
4. Run its query, for example:
       sum(5, S).
5. To load another file, use its name:
       [q27].
6. Exit SWI-Prolog:
       halt.

You can also start a particular file directly:
       swipl -s q26.pl

IMPORTANT
- Save edits in VS Code before loading the file.
- The family-tree question gives gender facts but no parent-child facts.
  q32.pl includes clearly marked example parent relationships so its
  queries can demonstrate the requested relations.
- q33.pl and q37.pl are academic demonstrations, not medical advice.
- q40.html demonstrates HTML tags. For the WordPress practical, add
  the relevant content through WordPress posts/pages or a Custom HTML block.
